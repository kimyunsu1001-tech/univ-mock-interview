개인정보처리방침

최종 수정일: 2026년 9월 15일

1. 이 사이트가 수집하는 정보

'모의 면접 AI'(이하 "본 서비스")는 이용자의 개인정보를 별도 데이터베이스에 수집·저장하지 않습니다. 회원가입, 로그인, 결제 기능이 없습니다.

2. 무료 체험 모드 (API 키 불필요)

"무료로 체험하기" 모드에서는 이용자의 답변과 면접 설정이 본 서비스가 운영하는 Cloudflare Worker(프록시 서버)를 거쳐 Cloudflare Workers AI로 전송되어 질문이 생성됩니다. 이 과정에서 개인 식별 정보(이름, 연락처 등)를 별도로 요구하거나 저장하지 않으며, 부정 사용 방지를 위해 방문자의 IP와 요청 횟수만 최대 2일간 임시로 기록한 뒤 자동 삭제됩니다. 대화 내용 자체는 서버에 저장되지 않습니다.

3. 본인 API 키 모드

"내 API 키 사용" 모드에서는 이용자가 본인의 Anthropic API 키를 입력해야 합니다. 이 키는 이용자의 브라우저 localStorage에만 저장되며, 본 서비스의 서버로 전송되거나 저장되지 않습니다. 입력된 키는 오직 이용자의 브라우저에서 Anthropic API(api.anthropic.com)로 직접 전송되어 면접 대화를 생성하는 데에만 사용됩니다.

4. 자기소개서·학생부 입력 내용 및 면접 기록

맞춤 질문을 위해 입력하는 자기소개서·학생부 요약, 그리고 완료된 면접의 대화 기록도 API 키와 동일하게 이용자의 브라우저 localStorage에만 저장됩니다. 이 내용 역시 본 서비스의 서버로 전송되지 않으며, 면접 진행 중에는 Anthropic API로만 전송되어 질문을 생성하는 데 사용됩니다. 브라우저 저장공간을 지우면 함께 삭제됩니다.

생기부·자소서 파일 첨부 기능은 어떤 형식의 파일이든 선택할 수 있으며, PDF·DOCX·TXT·HTML 등 지원되는 형식은 오픈소스 라이브러리(PDF.js, Mammoth.js) 또는 자체 처리 로직을 이용해 이용자의 브라우저 안에서만 텍스트를 추출합니다. 이 과정에서 첨부한 파일이나 그 내용은 어떤 서버로도 전송되지 않습니다. 다만 라이브러리 코드 자체를 내려받기 위해 최초 1회 cdnjs.cloudflare.com에 접속하며, 이때 파일 내용은 함께 전송되지 않습니다. 지원하지 않는 형식(HWP, 이미지, 옛 doc 등)을 첨부하면 안내 메시지만 표시되고 해당 파일 내용은 처리되지 않습니다.

5. 음성 입력·출력(마이크·음성 면접 모드) 사용

음성으로 답변할 때는 브라우저 내장 음성 인식 기능(Web Speech API)을 사용합니다. 음성은 브라우저와 해당 브라우저가 사용하는 음성 인식 엔진(예: Chrome의 Google 음성 인식) 사이에서만 처리되며, 본 서비스는 음성 데이터를 별도로 수집·저장하지 않습니다. 마이크 버튼을 누르지 않으면 이 기능은 동작하지 않습니다. "음성 면접 모드"를 켜면 면접관의 질문을 브라우저 내장 음성 합성 기능(Speech Synthesis API)으로 읽어주고, 답변 음성은 인식 완료 후 텍스트로 변환되어 자동으로 전송됩니다. 음성 합성은 기기 내에서만 처리되며 외부로 전송되지 않고, 음성 면접 모드 사용 여부는 브라우저 localStorage에만 저장됩니다.

6. 광고 및 쿠키 (Google AdSense)

본 서비스는 Google AdSense를 통해 광고를 게재할 수 있습니다. Google 등 광고 제공업체는 이용자의 이전 방문 기록을 바탕으로 맞춤형 광고를 제공하기 위해 쿠키를 사용할 수 있습니다.

  • Google의 광고 쿠키 사용에 대한 자세한 내용은 Google 광고 정책 페이지에서 확인할 수 있습니다.
  • 이용자는 Google 광고 설정에서 맞춤형 광고를 비활성화할 수 있습니다.

7. 제3자 링크

본 서비스는 최신 면접 기출·후기 검색을 위해 Google, YouTube, Naver, 진학사 등 외부 사이트로 연결되는 링크를 제공합니다. 이용자가 해당 링크를 통해 이동한 외부 사이트에서 발생하는 개인정보 처리는 각 사이트의 개인정보처리방침을 따릅니다.
